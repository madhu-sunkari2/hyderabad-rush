# ☕ Hyderabad Rush! 🍪

A fast-paced, addictive browser clicker game inspired by the vibrant culture and street delicacies of Old City Hyderabad.

🎮 **Live Demo:** [Play on Google Cloud Run](https://hyderabad-rush-796910223127.us-central1.run.app)

---

## 🎯 Gameplay Features

- **Iconic Hyderabadi Delicacies**:
  - 🍪 **Osmania Biscuit** (+10 pts)
  - ☕ **Irani Chai** (+15 pts)
  - 🌶️ **Mirchi Bajji** (+20 pts)
  - 🍲 **Haleem Bowl** (+25 pts)
  - 🍮 **Double ka Meetha** (+30 pts)
- **Candy Crush-Level Combo Multiplier**:
  - Catch **3 of the same delicacy in a row** for an instant **2x multiplier** and an authentic auto-rickshaw horn sound!
- **Chain Reaction FEVER MODE**:
  - Catch 5 items in rapid succession to unlock **3x FEVER MODE** for 5 seconds.
- **Boss Levels (Levels 5 & 10)**:
  - Slow-descending **Shahi Biryani Handi (🥘)** worth **100 bonus points**!
- **Power-Ups**:
  - 🧲 **Magnet**: Pulls falling items toward the center.
  - ⏳ **Slow Motion**: Halves gravity speed.
  - ✨ **Double Points**: 2x points boost.
- **Audio Synthesizer (Zero External Audio Files)**:
  - Dynamic Web Audio API synthesizer with festive background ostinato, catch chimes, and rickshaw horn sound effects.
- **Local High Score Leaderboard & Daily Challenge Mode**.
